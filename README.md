### 🤖 AI engineering

I work across the full AI engineering stack — data curation, fine-tuning, evals, deployment, retrieval, and the context engineering that makes any of it actually useful in production.

**Flagship:** Successfully fine-tuned Gemma 3 4B (E2B) after **38 failed attempts** — using AWS SageMaker, Unsloth, and LoRA adapters on a custom 203k-row reasoning dataset (`justcovenant/rag-reasoning-sft`) covering 4 reasoning types including CoT with `<thinking>` tags. Also deployed a fine-tuned Llama 3.2 8B (`hypaai/hypa-llama3-2-8b-sft-2025-12-rvl`) to a SageMaker real-time endpoint with scale-to-zero autoscaling via inference components.

### ⛓ Multichain by design

I'm not a chain maxi — I'm a problem maxi. Every chain has things it does better than the rest, and shipping production systems means picking the right one per use case instead of forcing one chain to do everything.

| Chain | Why I reach for it |
|-------|---------------------|
| **Solana** | Sub-second finality and low fees — best fit for high-frequency consumer flows, escrow, and microtransactions |
| **Base** | EVM tooling depth, Coinbase distribution, and a real onchain creator economy |
| **Ethereum L2s** | Liquidity gravity and the broadest set of battle-tested DeFi primitives |
| **Cross-chain** | Routing intent — match settlement to where the user and the liquidity actually are |

**Tools I build with:** Anchor, viem, ethers, wagmi, RainbowKit, Privy, Foundry, Hardhat, Solana Web3.js, SPL tokens, ERC-20/721/1155, account abstraction, intent-based routing.
